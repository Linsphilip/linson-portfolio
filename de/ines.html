Akademischer Mitarbeiter

Elektrische Messtechnik, historische Prüfdaten und die Integration eines automatisierten dreiphasigen Energiezähler-Prüflabors.

Organisation

INES · Hochschule Offenburg

Schwerpunkte

Python / SQL Server / Node-RED / Modbus / MySQL / InfluxDB

Mein Beitrag

  • Analyse von mehr als 2 Millionen historischen Energiezähler-Prüfdatensätzen mit Python, Pandas und SQL Server.
  • Untersuchung von Messabweichungen, Langzeitdrift und gerätebezogener Stabilität.
  • Entwicklung von Abläufen zur Bereinigung, Validierung und Harmonisierung von Prüfdaten sowie zur KPI-Erstellung und technischen Berichterstattung.
  • Integration von Leistungsquelle, elektronischen Lasten, Referenzmesstechnik, Energiezählern und Klimaprüftechnik.
  • Steuerung und Datenerfassung mit Python und Node-RED; Gerätekommunikation über Modbus TCP/RTU, RS-485 und GPIB/VISA.
